# BOOKTI · 그림 뮤직비디오

교사의 노래와 학생의 독서 그림을 연결하는 단일 기기용 웹 MVP입니다. BOOKTI의 초콜릿색·황동빛·명조 스타일에 맞춘 독립 하위 화면입니다.

## 팀원과 실행하기

Node.js 20 이상이 필요합니다. 외부 패키지를 사용하지 않아 `npm install` 없이 실행할 수 있습니다.

```sh
git clone --branch feature/bookti-music-video https://github.com/yujung91/hey2.git
cd hey2
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 종료는 터미널에서 `Ctrl+C`를 누릅니다. 다른 프로그램이 3000번 포트를 쓰면 macOS/Linux에서 `PORT=3001 npm run dev`, Windows PowerShell에서 `$env:PORT=3001; npm run dev`로 실행합니다.

팀원의 변경 사항을 받으려면 저장소 폴더에서 `git pull --ff-only`를 실행합니다. 작업 중인 변경이 있다면 먼저 별도 브랜치에 커밋하세요.

## 공유 범위

GitHub에는 웹앱 코드와 예시 그림·연주가 담깁니다. **각자 브라우저에서 그린 그림·올린 노래·편집한 가사는 GitHub로 자동 공유되지 않습니다.** 학생의 그림 파일은 그림판의 ‘그림 저장’으로 내려받아 전달한 뒤 다른 기기에서 ‘그림 추가’로 불러올 수 있습니다. 실제 학생 작품을 저장소에 올릴지는 팀에서 별도로 정해 주세요.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면과 편집창 |
| `style.css` | BOOKTI 디자인, 모바일 배치 |
| `app.js` | 오디오 재생, 장면 편집, 그림판, 브라우저 저장 |
| `public/` | 예시 그림 4장과 40초 시연용 연주 |
| `server.js` | 로컬 개발용 정적 웹 서버 |

배포나 빌드 없이 로컬 브라우저에서 사용하는 웹사이트입니다.

기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. `npm run check`로 JavaScript 문법을 확인합니다.

## 사용

- 기본 예시: 어린 왕자 그림 4장, 직접 합성한 40초 시연용 연주. 실제 수업 노래나 보컬은 포함되어 있지 않습니다.
- 노래 카드의 업로드 버튼으로 오디오를 선택하고 ‘가사 편집’에서 한 줄씩 입력합니다.
- ‘직접 그리기’에서 마우스·터치·펜으로 그림을 그립니다. 색상 영역, 색조, HEX 코드, 빠른 색상, 붓 굵기, 지우개, 20단계 되돌리기, 모두 지우기를 지원합니다. 전체 지우기도 되돌릴 수 있습니다.
- 완성한 그림은 PNG로 다운로드하거나 장면으로 담을 수 있습니다. 그림판을 닫으면 편집 중인 초안에 반영됩니다. 작품에 영구 반영하려면 이름과 시간을 정한 뒤 ‘장면 저장하기’를 누릅니다.
- ‘그림 추가’에서 이미지, 학생 이름, 가사, 시작·끝 시간을 지정합니다. 편집창의 그림판으로 업로드한 이미지를 덧그릴 수도 있습니다.
- 카드 화살표로 순서를 바꾸면 최초 시작 시각부터 구간이 다시 이어집니다. 각 위치의 기존 재생 길이를 유지합니다.
- 가사나 카드를 누르면 해당 재생 구간으로 이동하며, 재생 및 감상 모드에서 시간이 맞는 장면을 보여줍니다.
- 겹치는 구간은 카드 순서가 우선하며 빈 구간에는 이전 그림이 유지됩니다.

작품 제목·가사·그림은 이 브라우저의 localStorage에 저장됩니다. 이미지는 최대 1400px JPEG로 최적화됩니다. 브라우저 저장 공간이 부족하면 저장 오류를 안내합니다. 오디오 파일은 세션 중에만 사용하므로 새로고침 후 다시 선택해야 합니다. 서버 업로드, 실시간 공동 작업, MP4 출력은 포함하지 않습니다.

## 기존 사이트 연결

현재 저장소에는 기존 BOOKTI 사이트 소스가 없습니다. 이 앱은 독립 페이지이며 기존 사이트에 메뉴를 실제 추가한 상태는 아닙니다. 기존 프로젝트에서 이 화면의 HTML/CSS/JS와 public 자산을 하위 경로로 이식하거나 별도 배포 주소에 메뉴 링크를 연결할 수 있습니다. 상단 BOOKTI 로고와 ‘책갈피 찾기’는 전달받은 기존 사이트 주소로 연결됩니다.

## 검증

Chromium 자동화로 오디오 재생·시간별 장면 전환·가사 편집·그림 업로드·순서 변경·삭제·브라우저 저장·감상 모드를 확인했습니다. 그림판은 실제 캔버스 픽셀로 색상·붓·지우개·되돌리기·전체 지우기를 확인했고 그림 저장 후 새로고침 복원과 390px 모바일 배치도 확인했습니다.
